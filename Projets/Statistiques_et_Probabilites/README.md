# Module : Statistiques et Probabilités

Ce dossier rassemble les projets de Statistique Inférentielle, de Modélisation Statistique et de Simulation Aléatoire.

---

## 📂 Contenu par Thématique

| Dossier | Sujet & Description | Fichiers | Format |
| :--- | :--- | :--- | :--- |
| **`Statistique_Inferentielle/`** | Estimation ponctuelle et par intervalle de confiance, tests d'hypothèses statistiques (Chi-deux, Student, ANOVA). | `TP2 de Statistique Serigne Dame GADIAGA.ipynb`<br>`serigne dame gadiaga tp stat.ipynb` | Notebooks Jupyter (Python) |
| **`Modelisation statistique/`** | Modèles linéaires (Régression linéaire simple et multiple), analyse de variance et résidus. | `Modélisation_Statistique.ipynb` | Notebook Jupyter (Python) |
| **`rapports_de_stat/`** | Comptes-rendus et devoirs pratiques de modélisation statistique. | `Modélisation_Statistique_TP2 PAR GADIAGA[1].ipynb`<br>`tp1 dame gadiaga.pdf` | Notebook / PDF |
| **`Simulation_aléatoire_Rendu/`** | Génération de variables aléatoires, méthode d'inversion, méthode du rejet, théorème central limite et simulations de Monte-Carlo. | `Compte rendu simulation aléatoire. serigne dame gadiaga.PDF` | Rapport PDF |

## 🛠️ Outils & Bibliothèques

- **Python** : `scipy.stats`, `statsmodels`, `numpy`, `matplotlib`, `seaborn`
- **Méthodes** : Tests de Shapiro-Wilk, Kolmogorov-Smirnov, régression OLS, simulation de lois (Normale, Poisson, Exponentielle, Binomiale).
