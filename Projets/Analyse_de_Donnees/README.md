# Module : Analyse de Données, Machine Learning & Deep Learning

Ce dossier regroupe l'ensemble des projets dédiés à la Data Science, au Machine Learning, au Deep Learning, au traitement du signal audio, au Traitement du Langage Naturel (NLP) et à la géolocalisation.

---

## 📂 Liste des Projets et Contenu

| Projet / Dossier | Description & Objectifs | Fichiers associés | Technologies |
| :--- | :--- | :--- | :--- |
| **`ANALYSE ET PREDICTION DES ELECTIONS PRESIDENTIELLES/`** | Analyse exploratoire de données politiques et modélisation prédictive des résultats électoraux. | `election presidentielle.ipynb` | Python, Pandas, Scikit-Learn |
| **`Analyse des assurances/`** | Prédiction des coûts et souscriptions d'assurance par modélisation prédictive. | `Projet perso assurance.ipynb`, `Assurance (1).ipynb` | Python, Seaborn, Scikit-Learn |
| **`By Zalando/`** | Classification d'images d'articles de mode (Fashion MNIST / Zalando Data). | `Fashion by Zalando.ipynb` | Python, PyTorch/TensorFlow, Computer Vision |
| **`Exploration d opinions et detection de polarite/`** | Analyse de sentiments (NLP) et détection de polarité sur du texte. | `Polarité.ipynb`, `Polarité.py` | Python, NLTK/TextBlob, Scikit-Learn |
| **`Frais de logement/`** | Régression prédictive sur les prix de l'immobilier et frais de logement. | `Housing prices.ipynb` | Python, Matplotlib, Scikit-Learn |
| **`Geodata/`** | Analyse et classification de données géospatiales et signaux RSSI (géolocalisation indoor/outdoor). | `Examen_Classification.ipynb`, `GEODATA...ipynb`, `RSSI_0.csv` à `RSSI_3.csv` | Python, GeoPandas, Scikit-Learn |
| **`Iris de Fisher/`** | Classification classique du jeu de données des Iris de Fisher (supervisé/non-supervisé). | `2_Iris de Fisher.ipynb` | Python, Scikit-Learn |
| **`Machine Learning/`** | Synthèse des algorithmes de Machine Learning (régression, arbres, classification, clustering). | `Machine learning.ipynb` | Python, Scikit-Learn |
| **`Projet GEOSPACIAL/`** | Traitement et cartographie de données géospatiales complexes. | `Geospatial_data.ipynb` | Python, Folium, GeoPandas |
| **`Projet Geo data localisation des cinemas/`** | Cartographie et analyse spatiale de l'emplacement des salles de cinéma en R. | `Cinéma.R` | Langage R, ggplot2, sf/sp |
| **`Sur-apprentissage et échantillonnage/`** | Étude du phénomène d'overfitting, techniques de régularisation et d'échantillonnage (Cross-Validation). | `Sur-apprentissage et échantillonnage.ipynb` | Python, Scikit-Learn |
| **`Titanic/`** | Défi de prédiction de survie sur le Titanic (Kaggle Dataset). | `titanic train.ipynb`, `train.csv`, `titanic_submission.csv` | Python, Pandas, Scikit-Learn |
| **`mon projet reseau de neurones/`** | Modèles de Réseaux de Neurones Convolutifs (CNN) pour la classification d'images. | `A_deep_introduction_to_CNN.ipynb` | PyTorch / TensorFlow |
| **`reconnaissance vocale/`** | Traitement du signal vocal, extraction de caractéristiques audio (MFCC) et classification d'empreintes vocales. | `recvoc1.py` à `recvoc3.py`, `test.py`, `test1.py`, `test2.py` | Python, Librosa, Scipy, NumPy |

```bash
jupyter notebook
```
Ou pour exécuter un script Python spécifique (ex. reconnaissance vocale) :
```bash
python3 "reconnaissance vocale/recvoc1.py"
```
