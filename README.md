# Portfolio de Projets Académiques et Scientifiques - Serigne Dame GADIAGA

Bienvenue dans le dépôt central de mes projets académiques et travaux scientifiques réalisés dans le cadre du parcours **MAM3** (Mathématiques Appliquées et Modélisation) et spécialisations connexes en Data Science, Génie Logiciel, Calcul Scientifique et Statistique.

---

## 📌 Structure Générale du Dépôt

Le répertoire principal [`Projets/`](./Projets) regroupe l'ensemble des travaux classés en **8 grandes disciplines** :

```
.
├── README.md                                    # Documentation globale (ce fichier)
└── Projets/                                     # Répertoire central des projets
    ├── Analyse_de_Donnees/                      # Machine Learning, Deep Learning, NLP, Traitement d'images, Géodata
    ├── Base_de_Donnees/                         # Travaux Dirigés et Pratiques en Bases de Données relationnelles (SQL)
    ├── Genie_Logiciel/                          # Programmation Orientée Objet (C++), Algorithmique et STL (TP1 à TP7)
    ├── Methodes_Mathematiques_et_Analyse_Numerique/# Analyse numérique, méthodes itératives (Jacobi, Gauss-Seidel)
    ├── Outils_de_Calculs_Scientifiques/         # C & MATLAB (Systèmes dynamiques, équations différentielles, modélisation)
    ├── Rapports_SAS/                            # Data Mining, Régression Logistique, Gradient Boosting sous SAS Enterprise Miner
    ├── Rapports_de_Vulgarisation/               # Revues d'articles scientifiques et synthèses de vulgarisation
    └── Statistiques_et_Probabilites/            # Statistique Inférentielle, Modélisation Statistique et Simulations
```

## 🛠️ Aperçu des Disciplines et Technologies

| Discipline | Description & Domaines d'application | Technologies & Langages |
| :--- | :--- | :--- |
| **[Analyse de Données](./Projets/Analyse_de_Donnees)** | Machine Learning, Deep Learning (CNN), NLP (Analyse de polarité), Traitement de la parole, Analyse spatiale (Geodata, R), Prédictions (Élections, Immo, Assurances). | Python (Jupyter, PyTorch/TensorFlow, Scikit-Learn), R, Librosa |
| **[Génie Logiciel](./Projets/Genie_Logiciel)** | Programmation Orientée Objet avancée, structures de données, polymorphisme, itérateurs STL, gestion mémoire dynamique. | C++ (C++11/14/17), GCC/Clang |
| **[Méthodes Mathématiques & Analyse Numérique](./Projets/Methodes_Mathematiques_et_Analyse_Numerique)** | Solveurs de systèmes linéaires, méthodes itératives de Jacobi et Gauss-Seidel, devoirs de modélisation mathématique pour l'ingénieur. | MATLAB / Octave |
| **[Outils de Calculs Scientifiques](./Projets/Outils_de_Calculs_Scientifiques)** | Simulation de systèmes dynamiques (Lotka-Volterra, Modèle épidémique Zombie), résolutions d'EDO (Euler implicite/explicite), programmation C. | C, MATLAB, EPS Graphics |

| **[Statistiques & Probabilités](./Projets/Statistiques_et_Probabilites)** | Statistique inférentielle, modélisation statistique avancée, méthodes de Monte-Carlo et simulation de lois de probabilité. | Python (Scipy, Statsmodels), R, LaTeX/PDF |
| **[Base de Données](./Projets/Base_de_Donnees)** | Conception de modèles relationnels (E/A, UML), requêtage SQL, normalisation et algèbre relationnelle. | SQL, SGBDR |
| **[Rapports de Vulgarisation](./Projets/Rapports_de_Vulgarisation)** | Synthèses critiques d'articles de recherche scientifique et vulgarisation scientifique. | PDF, Documentations scientifiques |
